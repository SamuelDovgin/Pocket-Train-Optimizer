# Iteration record

An early aggregate-only directness search selected a 21-train candidate, but a shape audit found a 79%-direct route and a turn above 100 degrees. That geometry was rejected before publication.

The next search enforced per-route directness ≥85% and turns ≤100 degrees. Its tuning-selected 27-train / 141-link candidate omitted high-impact shortcuts. Held-out uniform reward per train was about 0.79× the previous 38-corridor reference; long-run reward per train was about 1.08×. These are synthetic model outcomes, not real profit measurements.

The shape-only candidate data and simulation report are retained here. The final search adds map-derived shortcut-access pressures and uses fresh policy, selection and evaluation seeds. Current starting configuration is still excluded from selection.
